# Tales & Tone

Editorial content writing and brand voice studio founded by Dharsi Chauhan in Vadodara, Gujarat.

## Features
- **Editorial Brand Showcase**: Character-driven copywriting portfolio and services.
- **Supabase Contact Integration**: Automated inquiry submission to Supabase backend.
- **Admin CRM Portal**: Dedicated dashboard at `/admin` for tracking leads, updating status, and exporting data.
- **Vercel & Netlify Ready**: Pre-configured rewrites and caching headers.

## Deployment
Configured for instant deployment on [Vercel](https://vercel.com).
